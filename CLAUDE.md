# Magic Wand

This repository is a mono-repo for a grad school course project (EECE5644,
Machine Learning/Pattern Recognition): a system that recognizes wand gestures
from a camera and triggers an action. Read these documents before working:

- `README.md`: project introduction and an index of all documentation.
- `docs/architecture.md`: the system architecture. Start here.
- `docs/standards.md`: the standards that all development and documentation
  must follow.
- `docs/data-handling.md`: how datasets are stored and handled.

Each component has its own `CLAUDE.md` with component-specific instructions,
and its own `docs/` folder with requirements, design and tasks.
